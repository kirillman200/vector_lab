About this editor

About SVG Vector Lab

SVG Vector Lab is a free online SVG editor that runs entirely in your browser. Open an SVG file (or paste its markup), then edit the real elements: drag shapes and path points on the canvas, tune fills, strokes, opacity and transforms in the inspector, and watch the SVG source code update live as you work. When you're done, copy the cleaned markup or export it as an SVG or PNG file.

It's also built for learning how SVG works. Select any vector and the notes panel explains its coordinate model — how path commands like M, L, C and A draw lines, Bézier curves and arcs, and how attributes map to visible geometry. Nothing is uploaded: your artwork stays on your device, and work-in-progress is autosaved to your browser's local storage.

Features

  • Edit SVG paths point by point — drag endpoints and Bézier control points, or type coordinates
  • Visual editing for rects, circles, ellipses, lines, polylines, polygons, text, groups and use elements
  • Multi-select with shift-click or rubber-band, resize and rotate handles, snapping to other elements
  • Live synchronized source panel — edit the markup or the canvas, both stay in sync
  • Convert basic shapes into editable path commands
  • Undo/redo history, keyboard nudging, and autosave
  • Export clean SVG markup or render PNG at 1×–8× resolution
  • Free, open source (MIT), no signup, works offline

Focused SVG tools

Frequently asked questions

Is SVG Vector Lab free to use?

Yes. SVG Vector Lab is completely free and open source under the MIT license. There is no signup, no account, and no paid tier.

Are my SVG files uploaded to a server?

No. The editor runs entirely in your browser. Files you open, edit, and export never leave your device, and your work-in-progress is autosaved to your browser's local storage.

Which SVG elements can I edit?

Paths, rectangles, circles, ellipses, lines, polylines, polygons, text, groups, and use references — including their attributes, transforms, fill and stroke, and for paths every individual command and point.

Can I convert shapes into paths?

Yes. The Convert to path tool turns rects, circles, ellipses, lines, polygons, and polylines into equivalent SVG path commands you can then edit point by point.

Can I export my SVG as a PNG image?

Yes. You can download the current drawing as a clean SVG file, or render it to PNG at 1x, 2x, 4x, or 8x resolution with an optional background color.

Does SVG Vector Lab work offline?

Yes. It is a static page with no server dependency — once loaded it keeps working offline, and you can also download the project and open index.html directly from your disk.
